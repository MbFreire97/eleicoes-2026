Como funciona a apuração?

O painel consulta os arquivos públicos do TSE a cada 5 segundos enquanto a aba está visível.

Quando os dados mudam, a tela é atualizada e o novo ponto entra no histórico deste navegador. A aba oculta pausa as consultas; falhas ativam uma espera progressiva.

Importante: liderança parcial não é resultado definido. O alerta só é emitido quando o arquivo oficial trouxer essa indicação.
